# Security policy

KisanSetu may contain personal, farm, marketplace, and financial information. Never include real farmer data, account records, tokens, or uploads in a public issue or reproduction. Use synthetic examples only.

If private vulnerability reporting is enabled for this repository, use **Report a vulnerability** in GitHub's Security tab. Otherwise, contact the repository owner through the public GitHub profile. Include the affected version, impact, and a minimal reproduction with synthetic data.

There is no published response-time guarantee. Revoke exposed Django, database, Cloudinary, Gemini, or hosting credentials and rotate them in each owner-controlled provider. Do not use the demo with real personal, farm, health, or financial records before qualified privacy/security review and documented consent/retention controls.
